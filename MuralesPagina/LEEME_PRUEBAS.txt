CAMBIOS DE SESION, COMENTARIOS Y PANEL ADMINISTRADOR

1) ENCENDÉ Apache y MySQL en XAMPP.
2) Colocá la carpeta MURALES-URBANOS-BASE dentro de C:\xampp\htdocs\
3) No abras el HTML haciendo doble clic. Entrá mediante http://localhost/.
4) Abrí:
   http://localhost/MURALES-URBANOS-BASE/frontend/index%20(1).html

REGISTRO NORMAL
- La ventana ahora tiene una sola caja de "Iniciar sesión".
- La opción "Registrarse" pide únicamente usuario, correo y contraseña.
- Al registrarse correctamente, el usuario queda conectado automáticamente.

ADMINISTRADOR
- Dentro de la misma ventana está "Ingresar como administrador".
- También se dejó una opción interna para crear la cuenta de administrador usando la clave exclusiva.
- Al crear o iniciar sesión como administrador, aparece el botón "Panel administrador".
- Si no hay sesión de administrador, ese botón permanece oculto.

ICONO DE SESION
- Cuando hay una sesión activa aparece un icono de usuario fijo al costado.
- Al tocarlo se ve el usuario y, si corresponde, el enlace al panel.
- Desde allí se puede cerrar sesión.

COMENTARIOS
- Solo un usuario registrado puede comentar.
- La columna `publicado` de la tabla comentario es el ESTADO del comentario:
  "para revisar", "publicado" o "rechazado".
- El comentario de un usuario se guarda como "para revisar".
- El administrador los modera desde "Administrar Murales" (sección
  "Moderación de comentarios", pestañas Para revisar / Publicados / Rechazados)
  y puede publicarlos, rechazarlos o devolverlos a revisión.
  (admin.php también sigue mostrando la misma moderación.)
- Solo los comentarios "publicado" aparecen en las páginas de murales.
- Los comentarios del administrador se guardan directamente como "publicado".
- La fecha del comentario ahora está en la columna `fecha`.
- Si ya tenías la base creada, ejecutá backend/actualizar_estado_comentarios.sql
  (no borra datos). Si no, usá murales.sql completo.

BASE DE DATOS
- La base debe llamarse EXACTAMENTE murales (no murales_dd, no murales.dd).
- Si en tu phpMyAdmin tenés una base vieja llamada murales_dd (o cualquier
  otra que no sea "murales"), borrala: ya no se usa para nada.
- Usá un solo archivo: backend/murales.sql. Ese archivo crea la base
  "murales" completa (todas las tablas, ya con usuario/password, estado del comentario,
  autor/direccion/estado_publicacion en mural) y de paso carga 2 murales
  de ejemplo para poder probar la página de Reporte enseguida.
  Los archivos murales_dd.sql, murales_dd_php.sql y los "actualizar_*.sql"
  sueltos ya no existen: todo quedó unificado en murales.sql.
- Si ejecutás murales.sql de nuevo, es seguro: borra y vuelve a crear las
  tablas (DROP TABLE IF EXISTS), así que no queda mezcla de estructuras
  viejas y nuevas.
